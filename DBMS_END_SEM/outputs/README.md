# Outputs Directory (`outputs/`)

This directory holds generated, reproducible analytical artifacts from Deliverables 1–4:

- **`tables/` (`28` CSV files):** Strictly aggregated summary tables, statistical test outputs, model metrics, and cost-value scenario tables. **Verified free of any player-level `device_id` or `purchase_id` records.**
- **`charts/` (`16` PNG files):** Publication-ready charts generated by `src/task_1_analysis.py`, `src/task_2_deep_dive.py`, `src/task_3_analysis.py`, and `src/task_4_churn_analysis.py`.
- **`telemetry.duckdb` (Excluded):** The local DuckDB database built from `data/*.csv` by `src/build_duckdb.py` contains raw player-level tables and is excluded from GitHub and the submission ZIP via `.gitignore`.
